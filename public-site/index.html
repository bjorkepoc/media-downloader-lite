Privacy notice

The page sends the public link you submit to a minimal Cloudflare Pages Function. The Function fetches only supported public pages, returns short-lived source-media links, and does not intentionally store the submitted URL or media after the request. For TikTok's signed video CDN, it may replay anonymous platform session headers inside one request; they are discarded and never set in your browser.

Cloudflare, the source platform, its media CDN, and your network provider process ordinary connection data such as IP addresses. Their own terms and privacy notices apply. Operator logging and analytics are disabled.

Previewing or processing media transfers bytes into temporary browser memory or cache. A file appears in Downloads only when you choose a download action. Closing or reloading the page clears in-memory results.

Optional enhancement starts only after separate consent. The FFmpeg WebAssembly engine is fetched from the version-pinned jsDelivr CDN, so jsDelivr receives an ordinary network request. Source media and output are processed inside your browser, not by our Worker.

The visible sponsor placements are static and tracking-free. No browser cookies, localStorage, IndexedDB, advertising identifiers, or personalized-ad scripts are used. This notice and a suitable consent flow must be updated before any ad network or analytics is enabled.
